# Guide drafts

Guide pages for the boat, plane, drone and train, kept out of the published guide
(`.github/scripts/publish-pages.sh` copies `docs/guide` only) and its sidebar. They are as they
were when the guide narrowed to the land vehicles; a page that returns moves back into
`docs/guide/` with its `img/` and `widgets/` files and a `pages.json` entry, and is checked against
the code then. Their "see the forces" links name Forces examples the widget no longer has: the
boat, plane, drone and train models and examples of `docs/guide/widgets/forces.js` are in git at
commit 87910b2.
